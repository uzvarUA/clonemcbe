# ✨ Vibrant Visuals для Minecraft Bedrock (Android)

## 📥 Як встановити

1. **Завантажте Minecraft Bedrock 1.21+** (бажано клон, щоб можна бвстановити як другу програму).  
2. **[Завантажте патч‑файл tiers.bin](https://github.com/uzvarUA/uzvarUA/releases/download/v1.0.0-tiers/tiers.bin)** з будь‑якого джерела.  
3. **[Завантажте MT Manager](https://mt-manager.en.uptodown.com/android)** з офіційних чи альтернативних джерел.  
4. Відкрийте **MT Manager**.  
5. У першій вкладці відкрийте папку з файлом `tiers.bin`.  
6. У другій вкладці відкрийте завантажений Minecraft → **View** → перейдіть у `assets/assets`.  
7. У вкладці з патчем утримайте `tiers.bin` → виберіть **Add** → підтвердьте **OK**.  
8. Встановіть патчований APK Minecraft.  
9. Запустіть гру → **Video Settings** → виберіть **Vibrant Visuals**.

---

## ⚠️ Примітка
Якщо **Vibrant Visuals** після патчу все одно недоступний, це може означати, що ваш пристрій занадто слабкий і не підтримує цей режим навіть у модифікованій версії.
